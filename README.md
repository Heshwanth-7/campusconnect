# CampusConnect

CampusConnect is a mobile-first web app for campus events, QR tickets, and lost and found. The app currently includes account screens, a protected Home placeholder, and a public API health check.

## Local setup

Install Docker with Compose and use the Node.js LTS version selected by `.nvmrc`.

```sh
nvm install
nvm use
npm ci
docker compose up -d --wait
npm run dev
```

Open http://localhost:5173. The client proxies `/api` to Express on port 3000. Check it with `curl -fsS http://localhost:5173/api/health`. Mailpit's web UI is at http://localhost:8025.

PostgreSQL starts on port 5432. The mounted SQL creates `campusconnect` and `campusconnect_test` on first startup with a fresh volume. The test database uses a separate login.

## Checks

```sh
npm run lint
npm run build
npm test
```

Lint uses TypeScript's strict and unused-code checks. The test runner loads `server/.env` when present and requires `DATABASE_URL_TEST` before applying Prisma migrations. You can also set the variable in your shell. See `server/.env.example` for the local database settings. The health route itself is a liveness check.

## Manual auth checklist

Start PostgreSQL and Mailpit with `docker compose up -d --wait`. Apply the auth migration with `npm run db:deploy --workspace server`, then run `npm run dev`. Use the client URL configured in `CLIENT_URL` (normally http://localhost:5173).

- [ ] Go to Sign up and register with an address matching `ALLOWED_EMAIL_DOMAINS`. Use a password with at least 8 characters, including a letter, a number, and a special character like `!` or `@`. Sign-up and password reset both require a special character.
- [ ] Open Mailpit at http://localhost:8025, open the verification email, and click its link. Confirm the app says your email is verified.
- [ ] Log in with the new account and confirm Home greets you by first name.
- [ ] Refresh the page and confirm you stay logged in.
- [ ] Log out. Confirm you return to Login and opening Home again redirects to Login.

The service worker is generated by `npm run build`. It caches the app shell. API requests need a connection to the server. To regenerate the placeholder PNG icons locally, run `node scripts/generate-pwa-icons.mjs`.

## Demo events

Apply migrations with `npm run db:deploy --workspace server`, then run `npm run seed` against the local development database. The seed prints the demo account emails for the admin, organizer, and student, and adds eight approved events. The shared local demo password is `CampusDemo123!`. Set `DEMO_PASSWORD` on the first run to choose a different password. Rerunning the seed preserves the existing demo accounts and events.
